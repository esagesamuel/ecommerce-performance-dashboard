# E-commerce Performance Dashboard — Project Scope

## Objective

Analyse transactional e-commerce data to identify revenue trends, product performance, customer purchasing behaviour, repeat purchases and opportunities to improve commercial performance.

## Stakeholders

- E-commerce Manager
- Sales Manager
- Marketing Manager
- Product Manager

## Key Business Questions

1. How are revenue and orders changing over time?
2. Which products and countries generate the most revenue?
3. What are the average order value and average items per order?
4. What proportion of customers make repeat purchases?
5. Who are the highest-value customers?
6. Which customer groups require retention or re-engagement?
7. How much transaction value is affected by cancellations?
8. Are there seasonal purchasing patterns?

## Tools

- Excel
- Power Query
- PostgreSQL
- SQL
- Power BI
- Git and GitHub

## Dataset Limitations

The dataset does not contain website sessions, marketing costs, advertising channels or shopping-cart activity. Conversion rate, advertising return and cart-abandonment metrics are therefore outside the scope of this project.
